## Design system
All UI follows the Phone Theft First Aid design system in `/design-system`.
- Read `design-system/README.md` and `design-system/voice.md` before building any screen or writing copy.
- Use tokens from `design-system/tokens.css` (or `tokens.json`); never hard-code colours, sizes or fonts.
- Reuse components from `design-system/components/` (see each README and `index.d.ts`).
- Logos and pictograms are in `design-system/assets/`.
- Brief / requirements: `design-system/brandkit-requirements.md`.
